# LoanContractApp
A responsive multi-step loan contract web application built using HTML, CSS, JavaScript, and Excel integration.
## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery
- Google sheets
  
## Run Locally
1. Clone the repository
2. Open contract.html and replace action link with your own google sheet link
3. Open index.html
